Email Setup: What to Ask Your IT Department

AlarmX sends alerts by email through your own mail server. Please choose one of the two options below and return the checklist at the end of this page before the installation date.

?

Why AlarmX needs an email account

AlarmX never uses a third-party or vendor mailbox. It uses one outgoing mailbox for:

  • Alarm notifications to recipients who are set up to receive email
  • Password reset codes for AlarmX users
  • Notices to AlarmX administrators (for example, when the SMS modem is down)

AlarmX only sends - it never reads the mailbox. Volume is low: typically a few messages a day, more only during an alarm event.

The password is stored encrypted on the AlarmX computer and is never shown on screen.

i

Microsoft 365 and Gmail

Microsoft 365 (Exchange Online)

  • Option A settings: server smtp.office365.com, port 587, STARTTLS
  • SMTP AUTH must be enabled for the AlarmX mailbox - it is often turned off by default
Microsoft is phasing out password sign-in for SMTP. It is disabled by default for existing tenants from the end of December 2026, and the final removal date will be announced in 2027. For a long-term setup, Option B through a Microsoft 365 connector is recommended, since it does not depend on password sign-in.

Gmail / Google Workspace

  • Option A settings: server smtp.gmail.com, port 587, STARTTLS
  • The account needs 2-Step Verification turned on, and an App Password (16 letters) is used instead of the regular password
