Email Setup: What to Ask Your IT Department

AlarmX sends email alerts through your own mail system. Choose one option below and return the checklist at the end of this page before the installation date.

?

Why AlarmX needs an email account

AlarmX never uses a third-party or vendor mailbox. It uses one outgoing mailbox of yours for:

  • Alarm notifications to recipients who are set up to receive email
  • Password reset codes for AlarmX users
  • Notices to AlarmX administrators (for example, when the SMS modem is down)

AlarmX only sends - it never reads the mailbox. Volume is low: typically a few messages a day, more only during an alarm event.

A

Your internal mail server (SMTP relay) Recommended for closed sites

AlarmX hands its messages to a mail server inside your network. Only that server talks to the outside. The AlarmX computer needs no internet access and stores no password.

B

Microsoft 365 app (OAuth) No mailbox password

AlarmX sends through Microsoft Graph using an app registration - no mailbox password, and not affected by Microsoft turning off password login for SMTP.

Network

The AlarmX computer must reach login.microsoftonline.com and graph.microsoft.com on port 443 (HTTPS). Nothing else is needed.

Steps in Microsoft Entra admin center (about 10 minutes)

  1. Create or choose the mailbox AlarmX sends from, for example alarms@yourcompany.com
  2. App registrations - New registration. Name: AlarmX. Account type: this organization only. No redirect URI.
  3. API permissions - Add a permission - Microsoft Graph - Application permissions - Mail.Send. Then click Grant admin consent.
  4. Certificates & secrets - New client secret. Copy the secret Value right away (it is shown once) and note its expiry date.
  5. Recommended: limit the app to the AlarmX mailbox only, with Exchange Online RBAC for Applications or an Application Access Policy. Without this, the app can send as any mailbox in the organization.

Please also confirm

  • The mailbox is allowed to send through SMTP (client submission / SMTP AUTH)
  • The mailbox is excluded from multi-factor sign-in prompts, or an app password is provided instead
  • Outgoing connections from the AlarmX computer to the server and port above are allowed by the firewall

Provider notes

  • Gmail / Google Workspace: turn on 2-Step Verification and use a 16-letter App Password, not the regular password
  • Microsoft 365: use Option B instead. Microsoft turns off password login for SMTP by default from the end of December 2026

Passwords and secrets are stored encrypted on the AlarmX computer and are never shown on screen.
